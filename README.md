# 1234

工具脚本集合。

- [`mac/`](mac/README.md) — 把一台常开的 Mac 接到 claude.ai/code：在 Mac 上常驻运行 Claude Code 的 Remote Control，让网页端和手机能看到并操作这台 Mac 上的会话（含查看/修改本地 routine 的 prompt）。
- [`lark/`](lark/README.md) — 飞书/Lark 里"能看到哪些业务单元"是怎么决定的：单位（Unit）与部门的区别、组织架构可见范围的四条主规则、普通成员和管理员各自怎么查、以及为什么没有 API 能回答"这个用户能看到哪些单位"。（正文为意大利语）
