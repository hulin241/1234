# 1234

工具脚本集合。

- [`mac/`](mac/README.md) — 把一台常开的 Mac 接到 claude.ai/code：在 Mac 上常驻运行 Claude Code 的 Remote Control，让网页端和手机能看到并操作这台 Mac 上的会话（含查看/修改本地 routine 的 prompt）。
- [`wiseglow-desk/`](wiseglow-desk/README.md) — 飞书群机器人：在群里 @ 它、发材料、用自然语言让它起草和修改 NBO、LOI、土地意向书等各类文件，所有文档统一套用 WiseGlow 视觉规范；由 Claude Agent SDK 驱动，常驻在 Mac 上运行（说明为意大利语）。
